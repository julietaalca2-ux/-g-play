# ÖG PLAY

Proyecto aparte (no es la red social ÖG). Interfaz de consola ÖG5 hecha en React.

## Cómo abrirlo
Subí todos los archivos a un repositorio de GitHub (manteniendo la carpeta `src`) y activá GitHub Pages.
Necesita internet: carga React, Tailwind e íconos desde un CDN.

## Archivos
- `index.html`: página principal.
- `app.js`: la aplicación ya lista para el navegador (es lo que se ejecuta).
- `src/App.jsx`: código fuente completo de la aplicación (el que pegaste).
- `src/main.jsx`: arranque de React.
